# Figma collaboration language

Terms used to select and retain design inputs for development.

## Language

**Working Space**:
The area where designers continuously edit and explore designs.
_Avoid_: Frozen release, stable task baseline

**Design RC**:
A batch of design content periodically frozen for development, with subsequent batches published as design work progresses. It is separate from a software release candidate.
_Avoid_: Production artifact, permanently unchanging RC area

**Task design baseline**:
The exact design batch and reproducible state accepted as a task's implementation or comparison source. Its identity persists when another batch is published.
_Avoid_: Latest design, newest checkpoint in the file

**Design baseline switch**:
A user's explicit selection of a different design batch for an existing task.
_Avoid_: Freshness observation, automatic RC upgrade
